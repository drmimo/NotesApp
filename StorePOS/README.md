# StorePOS - نظام إدارة المتجر

نظام نقطة بيع (POS) مبني باستخدام C# و WPF مع قاعدة بيانات CouchDB.

## المتطلبات

1. **.NET 8.0 SDK** - يجب تثبيته على النظام
2. **CouchDB** - مثبت على الجهاز المحلي أو على جهاز آخر في نفس الشبكة المحلية

## تثبيت .NET 8.0 SDK

### على Windows:
- قم بتحميل المثبت من: https://dotnet.microsoft.com/download/dotnet/8.0
- شغّل المثبت واتبع التعليمات

### على Linux:
```bash
wget https://dot.net/v1/dotnet-install.sh -O dotnet-install.sh
chmod +x dotnet-install.sh
./dotnet-install.sh --channel 8.0
export DOTNET_ROOT=$HOME/.dotnet
export PATH=$DOTNET_ROOT:$PATH
```

## تثبيت CouchDB

### على Windows:
- قم بتحميل CouchDB من: https://couchdb.apache.org/#download
- ثبّته واترك الإعدادات الافتراضية (المنفذ 5984)

### على Linux (Ubuntu/Debian):
```bash
sudo apt-get update
sudo apt-get install couchdb
```

## إعداد CouchDB

1. افتح متصفح الويب واذهب إلى: `http://localhost:5984/_utils`
2. سجل الدخول باستخدام:
   - اسم المستخدم: `admin`
   - كلمة المرور: `sama.store`
3. يمكنك تغيير هذه البيانات من خلال تطبيق الإعدادات

## بناء وتشغيل التطبيق

### باستخدام سطر الأوامر (CMD):

```bash
cd StorePOS
dotnet restore
dotnet build
dotnet run
```

### إنشاء ملف تنفيذي:

```bash
dotnet publish -c Release -r win-x64 --self-contained true
```

سيتم إنشاء الملف التنفيذي في مجلد `bin/Release/net8.0-windows/win-x64/publish`

## مميزات التطبيق

### 1. الصفحة الرئيسية (السلة)
- إدخال الباركود عبر قارئ الباركود
- البحث عن المنتجات بالاسم
- إضافة المنتجات للسلة بالنقر أو مسح الباركود
- زيادة/إنقاص الكمية لكل منتج
- زر الدفع وزر الإلغاء
- عرض المجموع الكلي بخط كبير

### 2. صفحة المبيعات
- عرض جميع الطلبات المنفذة
- تفاصيل كل طلب عند النقر عليه
- عرض تاريخ ووقت الطلب
- عرض المنتجات وأسعارها وقت الشراء

### 3. صفحة المخزون
- إضافة منتجات جديدة
- تعديل المنتجات الحالية
- حذف المنتجات
- البحث عن المنتجات
- إدارة الباركود المتعدد لكل منتج

### 4. صفحة الإعدادات
- تغيير عنوان خادم CouchDB
- تغيير المنفذ
- تغيير بيانات الدخول
- التبديل بين الوضع الداكن والفاتح

## ملاحظات هامة

1. **الوضع الافتراضي**: التطبيق يعمل بالوضع الداكن افتراضياً
2. **اللغة**: الواجهة بالكامل باللغة العربية
3. **الأرقام**: تتبع تنسيق النظام المحلي
4. **حجم الخط**: مناسب لشاشة 14 بوصة
   - الأرقام والكميات: حجم أكبر
   - المجموع الكلي: أكبر حجم

## استكشاف الأخطاء

- تأكد من تشغيل خدمة CouchDB

- تأكد من صحة بيانات الدخول

### خطأ في البناء:
- تأكد من تثبيت .NET 8.0 SDK
- شغّل `dotnet restore` قبل البناء
